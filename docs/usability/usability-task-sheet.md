Status: PLANNED. No completed session is claimed. Use participant aliases and record build, machine, display scale and date on the observation form. Explain that PITWALL is an illustrative simulator. Let the user attempt each task; record any hints rather than silently coaching.

1. Launch PITWALL.

2. Configure a short five-lap race.

3. Create two named strategies.

4. Add a valid stop after lap 2.

5. Compare both strategies.

6. Identify the faster plan and its time advantage.

7. Explain the pit spike on the graph.

8. Enter a stop after the final lap and interpret the error.

9. Add an event and explain when it takes effect.

10. Run a 100-trial Monte Carlo experiment.

11. Explain what the win percentage means.

12. Start optimisation and cancel it; describe the feedback and whether further input is possible.

13. Save a scenario.

14. Change a setting, then reload the scenario and check the restored inputs.
